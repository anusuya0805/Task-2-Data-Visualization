# Task 2 – Data Visualization & Storytelling

This project focuses on analyzing the Superstore dataset and creating meaningful visualizations using Tableau.

## Tools Used
- Tableau
- PowerPoint

## Dataset
Sample – Superstore Dataset (CSV)

## Visualizations Created
1. Sales by Category  
2. Profit by Sub-Category  
3. Monthly Sales Trend  
4. Category & Sub-Category TreeMap  
5. Sales vs Profit Scatter Plot  
6. Category-wise Sales Pie Chart

## Insights
- Technology has the highest sales share.  
- Some sub-categories show negative profit due to discounting.  
- Sales peak during November & December, showing seasonal trends.  
- Phones, Chairs, and Storage dominate their categories.  
- Higher sales sometimes do not lead to higher profit, indicating pricing or discount issues.
